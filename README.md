# 赛道雷达

> 给一个 AI 细分赛道，联网调研 5 个产品，产出一张**每个数字都能点回源头**的对比表——查不到就明说查不到。

**在线演示**：**https://ys233816.github.io/track-radar/**

打开就是完整产品：切换赛道、看图表、点任意一格改数据。演示版不联网、不需要密钥。

**📓 [项目日志](JOURNAL.md)** —— 这个项目是怎么长出来的：三个被否掉的方向、代码里三条不变量的由来、评测跑出的真数字，以及**我在过程中犯的三个错**。如果你只想看一样东西，看这个。

---

## 它解决什么问题

做赛道速览时，真正难的不是"搜不到产品"，而是两件事：

1. **搜到的一堆东西能不能放在一起比**——A 是 `$20/月`，B 是"免费版 + 按量"，C 是"联系销售"，塞进同一张表需要判断和归一；
2. **哪些话能信**——官网自吹"业界第一"不能当事实，第三方实测才算。

所以这个工具不生成"一份看起来专业的报告"。它生成**一张带来源和置信度的表，外加一份缺口清单**，把不能信的地方直接摊在明面上。

## 三条不变量

这个产品的价值就是这三条。它们写在**代码里**，不是写在 prompt 里——prompt 拦不住。

| # | 不变量 | 做法 |
|---|---|---|
| 1 | **编造率为 0** | AI 每给出一个 `source_url`，代码都拿去和本次检索**真实返回过的 URL 集合**比对。对不上 → 判定为编造，清空该值、降级为「未获取」，并把原始声称留档 |
| 2 | **推导字段不能比它的依据更可信** | 「起步月费」是从「起步价原文」换算来的，两者**必须同源**；拿不到原文时月费同步降级。否则读者会看到图表画着 `$19`、表格写着「未获取」 |
| 3 | **「未获取」是正常输出** | 查不到就标未获取并进缺口清单，**不允许用常识补全**。数值含多个数字（如"$69 月付 / $59 年付"）时拒绝猜测 |
| 4 | **来源够不够格，要单独判** | 每个来源按 6 级定级（官方定价页 / 官方文档 / 官方其他 / 第三方 / 聚合目录站 / 广告落地页）。**聚合站和广告页对任何字段都不够格**；价格类字段不接受官网首页或博客。在表格里以徽章标出、标红

判定规则全部写在代码里（[`lib/source-grade.mjs`](lib/source-grade.mjs)），不进 prompt。分级是 `source_url` 的**纯函数**，所以能回溯应用到历史语料——不用为了拿到等级重跑一遍调研。

### 不够格怎么办：自纠错闭环

第 4 条不变量只负责**发现**问题。发现之后走一个两段闭环：

```
来源不够格 → 定向重搜一次 → 够格了？ → 采用
                    ↓ 仍不够格
              降级为「未获取」（宁缺勿猜）
```

重搜时系统提示里**明确禁止拿原来源充数**。实测补证成功率约 **65.6%**（样本极小，见 [评测报告](eval/report.md)），**代价是字段值覆盖率下降**——不够格的引用是被**删掉**的，不是被**修好**的，两者必须一起报。

> ⚠️ 一个诚实的发现：模型被告知不许用原来源后，**多次换成了另一个同样是广告的页面**（例如把 `jasper.ai` 的首页广告链接换成 `jasper.ai/platform?gclid=...`）。原因不是模型不听话，而是**广告落地页和聚合站在搜索结果里排名本来就很靠前**。这说明「换个来源」这个思路本身有上限——搜索生态里好东西不总是排在前面。

`npm test` 有 42 条断言盯着这四条，测试数据全部取自真实调研输出。

## 一次调研怎么跑

```
选赛道 → 确认产品名单 → 逐个产品：联网抓取 → 归一字段 → 来源校验 → 渲染
                                        ↑ 两阶段，不合并
```

**为什么是两阶段**：**在本项目使用的 API 端点上**，`web_search` 工具与 `output_config.format` 结构化输出无法在同一次调用里共存——模型会改写 Markdown 而不是受约束的 JSON，且同样参数时灵时不灵。（这是该端点的实现限制，不一定适用于 Anthropic 官方 API。）

拆开之后反而更好：阶段一产出的 URL 清单，正好成为阶段二做来源校验的基准。**这个架构不依赖任何厂商专有特性**，换端点也不用改。

## 已知边界

这个项目**没有解决**的问题，写在最显眼的地方：

- **来源可验证 ≠ 内容正确。** 一格可以引用一个真实页面，却填进一段答非所问的页面碎片（实测：某产品的「部署方式」被抓成了帮助文档的导航句）。URL 校验拦不住这个。
- **来源可验证 ≠ 来源可信。** 广告落地页、聚合站、目录站都能通过校验。实测中某产品 6 个字段引用同一条搜索广告落地页。
- **没有任何线上验证。** 没有真实用户、没有埋点、没有 A/B。所有可用性判断都来自小规模离线核对。
- **慢。** 5 个产品约 5–7 分钟（并发 3）。这是联网抓取的真实成本，没有隐藏。

## 跑起来

```bash
npm install
npm start                       # → http://localhost:5178   （需要能调用 Claude API）
npm test                        # 三条不变量的断言
npm run build:demo              # 生成单文件演示版
```

**单文件演示版**：`npm run build:demo` 会把 CSS、JS 和**真实调研报告**一起烤进 `track-radar-demo.html`。双击即开，无后端、无密钥、无 CDN、离线可用。演示版里改数据是真的写进浏览器 localStorage，同一字段改满 2 次会当场升级为「高频错误点」——自进化钩子不是截图。

## 结构

```

public/            前端（手写 SVG 图表，无图表库）

test/invariants.mjs
build-demo.mjs     单文件打包
```

## 评测状态

评测已跑通。语料 = **10 轮真实联网调研 / 370 个字段槽位**，代码在 `eval/`，报告在 [`eval/report.md`](eval/report.md)，`npm run eval` 可一键复现。

**能机械判定的指标全部自动算，需要主观判断的一律留空并标注「需人工」**——不用一个看起来精确的数字掩盖它其实是猜的。

| 指标 | 实测 | 怎么读 |
|---|---|---|
| 编造率 | **1.62%**（6/370） | 3 轮触发拦截。其中 2 例是同一产品的多个字段一起被拦——**这类错误连片出现**，审计该按产品聚合而非按字段 |
| 跨字段同源违反 | **3 → 0** | 加入「推导字段必须与依据字段同源」后清零 |
| 价格覆盖率 | **78.9% → 55.6%** | ⚠️ **这是修复的代价，不是退步**。原本靠另一条独立来源凑出来的数字被拒绝了。宁可不给数，也不给两个来源互相打架的数 |
| L4-A 内容命中 | **93.3%**（14/15） | 从 326 个有值槽位中**等距抽样，不按成败预筛**。1 例失败见下 |
| **来源不够格支撑其字段** | **33.13%**（108/326） | ⬅️ **本项目最大的发现**。URL 校验只能判断「链接真的存在」，判断不了「它够不够格支撑这条事实」。其中 17.1% 是广告落地页、16.7% 是聚合目录站——**两者都能通过 URL 校验** |
| **补证闭环成功率** | **65.6%**（21/32） | 不够格的来源定向重搜一轮后：21 个救回、11 个降级。⚠️ 只统计账目正确的 2 轮；产品间方差极大（0% ~ 100%），**均值不可用于描述它** |
| 补证的覆盖率代价 | 95.6% → **70.0%** | ⚠️ **归零不是能力提升，是口径变化**——不够格的引用被删掉了，不是被修好了 |
| 汇总指标不一致 | 0 | 报告计数与逐格实算完全吻合 |
| 图表↔表格冲突 | 0（修复后） | 修复前有 3 例「图表画了值、表格写未获取」的矛盾 |

**唯一被记下的 L4-A 失败**：Fathom 的「部署方式」填进了帮助文档的引导句 *"Use this section as a quick way to audit that you've installed our Desktop App…"*。**它通过了来源校验**——URL 真实存在、来自官方帮助中心。所以这类失败 URL 校验拦不住，只能靠人工读内容。这条 case 是这个项目最有价值的失败样本。

### 这份评测**不能**得出的结论

- ❌ 不能把 93.3% 当稳定准确率——只标了 15 条，一个 case 就值 6.7 个百分点
- ❌ 不能推出「修复后整体变好」——同源违反清零了，但价格覆盖率同时腰斩
- ✅ 只有一条口径够硬：**来源校验在 370 个槽位中拦下 6 个编造字段**，逐条可查
- ⚠️ 人工标注者是 AI 助手本人（非领域专家），**未做标注者间一致性检验**——写进任何材料都必须如实说明
- ⚠️ 样本只覆盖 2 条赛道，**不能外推**
